## Regime rules (always scan when NYSE open / not intraday-ban)
| Mode | Condition | New BUYs |
|------|-----------|----------|
| HARD_HALT | VIX ≥ 25 **or** SPX < 0.98×SMA50 | None — would-be buys → SKIP `REGIME_HARD_HALT`; still download+scan+near-miss |
| SOFT | SPX < SMA50 but ≥ 0.98×SMA50, VIX < 25 | STOCK only if RS≥90 + DWM green + setup; ETF/COMMODITY → SKIP `REGIME_SOFT_ETF_BLOCK` |
